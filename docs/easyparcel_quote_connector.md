# EasyParcel quotation connector boundary (read-only preparation)

This branch adds an **authenticated, owner-scoped quotation readiness view**, not a live EasyParcel Open API connection. The reported planning test frontend is `https://kargokawanai-planning-test.streamlit.app`; the Render backend is `https://kargokawan-oauth.onrender.com`. This branch was neither deployed nor connected to those services by Codex. The reported EasyParcel Platform Integration Client Secret was exposed. **Rotate or replace it in the Developer Hub before any sandbox handshake. Do not put that old secret in Render, Streamlit, fixtures, source, logs, or support messages.**

## Architecture and provenance

`EasyParcelOpenApiQuoteAdapter` is a server-side, read-only interface. Its `request_rates` method always returns `NOT_CONNECTED`, zero observations and no carrier side effects, including when `EASYPARCEL_QUOTE_CONNECTOR_ENABLED=1`. The flag defaults off and is **not an OAuth enable switch**: a later reviewed implementation must separately add verified account linking, durable encrypted token storage and a documented rate endpoint/response contract. The existing `EasyParcelAdapter` in `carrier_adapters.py` is for the separate legacy **Individual API key** and its documented `EPRateCheckingBulk` response. Its credentials, authentication method and response fields must not be reused as an Open API OAuth contract.

Render's `GET /pilot/jobs/{job_id}/easyparcel/readiness` verifies the existing Google OIDC token before reading. `PostgresPilotStore` selects the job and its quote drafts using the verified owner subject. It returns the connector status, one missing-complete-courier-quote action per uncovered order, and review outcomes for saved manual EasyParcel evidence. The existing `hybrid_quotes.review` applies route, deadline, full-payable-cost, tax, surcharge, expiry, dimensions, weight and provenance checks. A `PUBLIC_REFERENCE` starting price or incomplete draft stays excluded. Manual evidence remains `USER_IMPORTED_UNVERIFIED`, even if the operator writes an authentication claim in its reference. The endpoint makes no provider request and saves no new record; it cannot change approvals. Quote revisions still change the private plan fingerprint and reject stale approval. The existing planner, explicit approval, append-only audit and **NOT A BOOKING** manifest are unchanged.

`FixtureEasyParcelQuoteAdapter` and `synthetic_demo_transport` implement an **internal test schema**, not an EasyParcel response. The fixture preserves explicitly supplied MYR values, components, timestamps and transit days, leaving missing fields `null`; a delivery text like “2–4 days” is not promoted to a guarantee. Every fixture observation is `SYNTHETIC`, `TEST_ONLY`, `full_cost=false` and excluded from real planning. Invalid services get explicit rejection reasons. `NO_SERVICES`, `TRANSPORT_ERROR`, `AUTHENTICATION_ERROR`, `MISSING_SHIPMENT_DATA` and `UNTRUSTED_RESPONSE` remain distinct. The fixture preview in Streamlit is ephemeral and cannot be imported through the pilot quote API, which rejects `SYNTHETIC` and user-claimed `LIVE_AUTHENTICATED` records.

## Safe fixture demonstration

1. In a **local** or reviewed test deployment, sign in as the allowlisted pilot operator. Select a fictional private job such as the five-order sample. The new **EasyParcel quotation readiness** section shows `NOT_CONNECTED` and missing complete courier-quote actions for each uncovered order.
2. Expand **Preview a TEST_ONLY synthetic rate response**, choose a fictional order and click **Preview synthetic EasyParcel fixture**. The displayed synthetic MYR 17.25 observation has no all-in payable total, tax/surcharge treatment, validity or guaranteed transit evidence. It is not persisted and cannot complete the real plan. No provider API call is made.
3. Upload an independently obtained manual quote through the existing reviewed CSV path if available. The readiness table will show its `USER_IMPORTED_UNVERIFIED` source, status and exclusion reason. Request a private plan separately; it remains **NOT READY** until every order has eligible coverage from the existing quote rules. A plan still requires explicit approval.

## What is verified and what is not

The repository's [Individual API setup guide](provider_api_setup.md) documents `EPRateCheckingBulk` for an API key and known response fields. The [Open API OAuth guide](easyparcel_oauth_deployment.md) documents authorization-code start, callback, token exchange and refresh mechanics. Neither source establishes, for this application, a verified **Open API OAuth rate request endpoint and response schema**, read-only permission/scope, account identity binding, payable price/tax/surcharge semantics, quote validity, or a safe sandbox rate check. No API endpoint, request payload, scope, service eligibility or quote ID was guessed in this branch. No real EasyParcel quote was collected.

Before any future live sandbox test, the operator must:

1. Rotate/revoke the exposed Client Secret and verify the replacement remains only in a server-side secret manager. Do not reuse the old secret.
2. Obtain current official EasyParcel Open API documentation or written provider confirmation for the **OAuth-authorized rate request**, its route/weight/dimension fields, response structure, pagination/errors/rate limits, account identity, allowed scope and sandbox environment. Confirm whether read-only quotation access is granted to this Platform Integration; Individual API credentials are not interchangeable.
3. Establish durable encrypted OAuth token storage outside Render Free's ephemeral filesystem, bind one verified EasyParcel account to the allowlisted operator, and complete security review of state, refresh, revocation and token isolation. The production `/oauth/easyparcel/start` and `/callback` routes currently return 403.
4. Confirm how a returned rate becomes a **complete payable quotation**: tax, surcharges, add-ons, member tier, restrictions, precise route coverage, transit evidence, issuance time and expiry. A starting or partial rate must remain a non-executable observation.
5. Implement a separately reviewed server-side adapter and run one authorized sandbox handshake using only replacement credentials. Keep token, secret, customer addresses and raw provider payloads out of UI, logs and manifests. Demonstrate owner isolation and no carrier write calls before considering live enablement.

`EASYPARCEL_QUOTE_CONNECTOR_ENABLED` is an optional future server-side feature flag (default unset/off); setting it now **does not connect or call EasyParcel**. No new secret or Render setting is required for the current read-only readiness view. This branch does not book, pay, create or cancel shipments, or update tracking.
