# KargoKawan competition demo (2–3 minutes)

1. Open the Streamlit app and scroll to **Competition demo · mixed methods**.
   Point out the permanent **SIMULATED DEMO — NOT REAL CARRIER PRICES** banner.
   Select **Load Demo Scenario**. Four fictional orders share one KL pickup and
   have four explicit destination postcodes. No CSV or API account is needed.
2. Show the side-by-side figures: standalone fictional courier quotes total
   **RM80.00**; the fictional mixed plan totals **RM55.00**. The mixed plan uses
   one three-stop vehicle quote at RM35 and one parcel quote at RM20. This RM25
   difference is only a synthetic illustration. Show quote IDs, covered orders,
   stop sequence, source evidence and solver status.
3. Select **Preview demo plan**, then **Approve demo proposal**. Explain that
   approval records a local proposal; it makes no booking or payment.
4. Check **Simulate disruption: vehicle provider unavailable**. The approved
   proposal clears. The recalculated synthetic plan uses four parcel quotes for
   RM80. Preview and approve again to show the review gate after replanning.
5. If time permits, point to the separate imported real quotation and research
   sections. Manual quotations remain user-supplied and unverified. Live carrier
   adapters are not connected.
