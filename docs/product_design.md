# KargoKawan public workspace design

The public fictional workflow remains Orders → Plan → Approve → Prepare. `festival_demo.py` owns state and invokes the existing validator, quote review, deterministic optimiser, fingerprinted preview/approval and manifest. `product_ui.py` contains presentation-only order, route, cost and decision patterns. It escapes dynamic text before placing it in HTML; all actions remain native Streamlit buttons, inputs and downloads. The OIDC pilot and advanced tools remain separate.

The design uses warm paper `#F6F3EC`, deep ink `#182C35`, forest green `#33766D`, amber route emphasis, white surfaces and `#DFE5E1` borders. The Streamlit theme lives in `.streamlit/config.toml`; app styling is centralised in `product_ui.STYLE`. Cards use one consistent radius and compact spacing. Prices use tabular figures. Browser focus remains visible, and the single primary action stays native. No order data is inserted into markup without HTML escaping.

Orders present a compact two-column list on desktop, with the planning action before the list; Streamlit should stack the columns at narrow widths. Plan has a distinct dark cost summary, then a highlighted selected van route and secondary courier routes. Approval has a concise white decision surface, while Prepare leads with the approved manifest and keeps generated tasks optional. Quote references, exclusions and solver diagnostics remain in the calculation expander.

Local Chromium visual review covered desktop Orders, Plan, Approval and Prepare at approximately 1212px browser-window width. The first captures showed the planning button too far down, a stale Orders heading on Plan and repeated approval details; these were corrected in source. Prepare was given a distinct approval surface after review. Chrome's managed policy blocked DevTools device emulation, so 1366px, 1440px, 768px and 375px exact-width visual checks, plus keyboard and screen-reader review, remain manual. AppTest covers stage actions and state but cannot establish pixel-level quality.
